SysManage Flatpak Repository

Install the SysManage agent as a Flatpak from the signed SysManage repository.

Before You Choose the Flatpak

The Flatpak agent can only report on the host. Its sandbox stops it from managing packages, services or users, so it cannot install updates or change anything. For a full agent, install the regular package for your distribution from Agent Installation.

  • Built for x86_64 Linux.
  • Installs for one user and runs as a systemd user service, not as a system service.
  • Flathub hosts desktop applications rather than background services, so the agent is published in its own repository.

Install

1. Add the Repository

The repository is signed with the SysManage Package Signing key, which the .flatpakrepo file carries, so Flatpak verifies every download. The key's fingerprint is 896E ED43 9F5E 9BB1 FCA6 69A5 E033 E691 377F 0AE3.

flatpak remote-add --user --if-not-exists sysmanage https://sysmanage.org/sysmanage.flatpakrepo

2. Install the Agent

flatpak install --user sysmanage org.sysmanage.Agent

3. Point It at Your Server

The first run creates the configuration file at ~/.var/app/org.sysmanage.Agent/config/sysmanage/sysmanage-agent.yaml. Run the agent once, stop it with Ctrl+C, then replace the server section of that file with your server's address:

flatpak run org.sysmanage.Agent
vi ~/.var/app/org.sysmanage.Agent/config/sysmanage/sysmanage-agent.yaml
server:
  url: "https://sysmanage.example.com"
  verify_ssl: true

4. Run It as a Service

The Flatpak ships a script that installs, enables and starts a systemd user service for the agent. Run it on the host, outside the sandbox:

bash ~/.local/share/flatpak/app/org.sysmanage.Agent/current/active/files/share/sysmanage-agent/scripts/sysmanage-service-install.sh
systemctl --user status sysmanage-agent

A user service stops when you log out. To keep the agent running without a login session, enable lingering for your account: loginctl enable-linger.

5. Approve the Host

Within a minute the host appears on the server's Hosts page waiting for approval. See Agent Approval.

Updating

flatpak update --user org.sysmanage.Agent
systemctl --user restart sysmanage-agent

Configuration, Data and Logs

  • Configuration: ~/.var/app/org.sysmanage.Agent/config/sysmanage/sysmanage-agent.yaml
  • Database: ~/.var/app/org.sysmanage.Agent/data/sysmanage/agent.db
  • Log: ~/.var/app/org.sysmanage.Agent/data/sysmanage/logs/agent.log, and journalctl --user -u sysmanage-agent

Uninstalling

# 1. Stop and remove the user service
bash ~/.local/share/flatpak/app/org.sysmanage.Agent/current/active/files/share/sysmanage-agent/scripts/sysmanage-service-uninstall.sh

# 2. Remove the Flatpak
flatpak uninstall --user org.sysmanage.Agent

# 3. (Optional) Remove the repository
flatpak remote-delete --user sysmanage
