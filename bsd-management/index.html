Native package tools on every BSD

SysManage speaks each BSD's native tools -- FreeBSD pkg and freebsd-update, OpenBSD pkg_add, syspatch and sysupgrade, and NetBSD pkgin -- so software management feels native on every host. What each can do differs: updates are applied on FreeBSD and to OpenBSD's base system, NetBSD updates are detected but not yet applied, OS upgrades run on FreeBSD and OpenBSD, and CIS and DISA STIG compliance checks are Linux-only today. The supported platforms page lists every difference.

  • FreeBSD pkg, OpenBSD pkg_add, and NetBSD pkgin
  • Inventory and software discovery on every BSD
  • Updates applied on FreeBSD and to OpenBSD's base system; detected on NetBSD
  • CVE vulnerability scanning on all three BSDs (Professional; OpenBSD covers the base system); compliance checks are Linux-only
