What the evaluation needs

One server

An Ubuntu 24.04 LTS virtual machine with 2 CPUs, 4 GB of memory and 25 GB of disk. It can also be the first host you manage.

Two operating systems

The walkthrough uses Ubuntu and FreeBSD; Windows works the same way. Pick the two that cause you the most work today.

Outbound 443 only

Agents connect out to the server on port 443. Nothing connects in to your hosts, and the Community edition has no license check and never contacts us.

About 30 minutes

Installing the server, connecting two hosts and running the first operation. Every step was tested on fresh machines.

What success looks like

  • Both hosts in one inventory, with the same detail for each.
  • Pending updates for both in one list, security updates first.
  • A package installed on both from one console -- apt on one, pkg on the other.
  • The approvals and the installation in the audit log, with who did them and when.

What Community includes

Inventory, updates, OS upgrades, maintenance windows, scripts, users and groups, role-based access, multi-factor sign-in, the audit log and the API -- free, with no host limit. Vulnerability scanning and compliance checks start at Professional; fleet automation and configuration management at Enterprise. Every capability, by edition.
