Roadmap

SysManage ships in four editions -- Community Edition, Professional, Enterprise, and Multi-Tenant SaaS -- built from one codebase and one agent. Below is an honest snapshot of what's available today and what we're building next. Dates aren't promises: priorities move with what operators actually need.

Available today

🏠

Community Edition

Free, open-source, and self-hosted on a single server and database. A persistent agent for Linux, Windows, macOS, FreeBSD, OpenBSD, and NetBSD; real-time WebSocket monitoring; hardware and software inventory; package and OS update management; maintenance windows so updates land when you expect them; user and access management; tagging; firewall status; ad-hoc scripts; reporting; database high availability, so the server runs against a Patroni / pg_auto_failover / Stolon cluster and survives a primary failover without manual intervention -- point it at a proxy VIP or a libpq multi-host DSN and pooled connections re-resolve to the new primary on their own; agent capability reporting, so a mixed fleet shows what each agent can actually do on its platform; an endpoint fact store that answers queries in osquery's own table schema on every platform the agent runs on -- natively on OpenBSD and NetBSD, where osquery does not exist, with osquery itself as an optional provider elsewhere; and an audit log.

📊

Professional

Everything in Community Edition, plus AI-assisted health analysis with score history, CVE vulnerability scanning, vendor errata and advisory management, OS end-of-life tracking with maintenance-window-aware release upgrades, CIS / DISA STIG compliance auditing, alerting to email / webhook / Slack / Teams, scheduled PDF reporting, an expanded audit trail, secrets management backed by OpenBAO, LXD and WSL container management, provisioning-template authoring, and curated, versioned query packs assigned per host, tag or site, with ad-hoc fleet-wide live query.

🏢

Enterprise

Everything in Professional, plus FIPS compliance-mode management, antivirus management, firewall orchestration, automation at fleet scale, full VM lifecycle management (KVM, bhyve, and OpenBSD vmm), observability via OpenTelemetry / Grafana / Graylog, content views and lifecycle environments with gated promotion, a Snap Store proxy and container-image content lifecycle, image-mode (bootc / rpm-ostree) host management, desired-state configuration management across Ansible, PowerShell DSC, Puppet, Salt and Chef -- with scheduled enforcement, fleet-scale job templates and inventories, baseline capture, drift detection that extends to arbitrary files and configuration state, one-click remediate-to-baseline and targeted remediation playbooks -- an advisor that scores risk-ranked recommendations over the fleet's evidence, reports what it could not assess instead of counting it as clean, and proposes fixes for an operator to approve, host provisioning -- both on external hypervisors and bare metal over PXE, with hardware discovery -- multi-factor authentication and external IdP single sign-on, fully air-gapped deployment (including private mirrors for the agent's own install channels, so hosts provisioned inside an enclave still enroll), and multi-site federation.

🌏

Multi-Tenant SaaS

Everything in Enterprise, run as a control plane that hosts isolated tenants -- a database per tenant, customer-owned SSO, and per-tenant edition assignment so each tenant can be set to Community, Professional, or Enterprise independently.

On the roadmap

The next stretch closes the gap with established fleet-management tools while keeping our footing as the management-and-remediation plane rather than another agent to babysit. The edition each lands in is noted per item.

Provisioning & discovery

Bare-metal PXE provisioning, per-machine OS assignment, hardware discovery, and provisioning onto external hypervisors all ship today, on remote libvirt and Proxmox. Still ahead are the compute providers deferred out of that work: EC2, Azure and GCE for public-cloud provisioning, and VMware / vSphere. Enterprise.

Configuration management at fleet scale

Desired-state configuration across Ansible, PowerShell DSC, Puppet, Salt and Chef ships today, along with scheduled enforcement per host, tag or site, baseline capture, drift detection and one-click remediate-to-baseline. Fleet scale ships too: inventories built from your hosts, tags and sites, job templates that run one profile across thousands of machines in bounded waves with a per-host result, and remediation playbooks that repair a single divergence rather than re-applying a whole baseline -- optionally unattended. Enterprise.

Proactive operations & advisor

The advisor ships today: risk-scored recommendations across your collected facts, CVEs, compliance results and configuration state, with curated rule packs and proposed fixes. Still ahead: signature and YARA malware detection, and a guided threat-model wizard that turns your answers into a prioritized posture punch list with audited waivers. Enterprise unless noted. The same fact store also feeds built-in metric graphs over retained samples, which flow through to the existing Prometheus endpoint for Grafana (Professional+).

Security tooling coexistence

Meeting you where you are rather than replacing what you already run: orchestrating Velociraptor for incident response and threat hunting, and ingesting Wazuh alerts into the same alerting, reporting and audit surfaces as everything else. Enterprise.

Mobile devices & MDM

Phones and tablets as a first-class endpoint class rather than an afterthought. Inventory and OS / patch-level visibility for iOS, iPadOS and Android in Community Edition; ingestion from the UEM you already run -- Microsoft Intune, Jamf Pro, Workspace ONE, Kandji -- at Professional; a companion self-report app for the BYOD devices no UEM covers; and ultimately native MDM authority over the Apple MDM protocol and the Android Management API, with zero-touch enrollment, at Enterprise.

Broader hardware support

The agent on the enterprise iron and emerging silicon beyond x86-64 and arm64 -- IBM Power (ppc64le), IBM Z (s390x) and RISC-V (riscv64), including the big-endian correctness work that s390x demands. The agent is open source, so this lands in Community Edition.

Unmanaged asset visibility

What is on your network that SysManage does not manage. Agents already sit inside each segment, so they report the neighbors they can see -- passively by default, with active sweeps opt-in, scoped and audited -- and anything already covered by a managed host is filtered out. The result is a review page, not an onboarding pipeline: we detect unenrolled machines, we do not force-enroll them, because that would need credentials on the target and reintroduce the inbound access the architecture deliberately avoids. Devices you would never manage -- an IoT sensor, a printer, a switch -- get allow-listed away for good, with a reason and an owner recorded. Enterprise.

High availability & disaster recovery

Survive losing a server, and survive losing a site. Several SysManage servers running active behind a load balancer, with the scheduled work leader-elected so it still runs exactly once; integration with the PostgreSQL failover managers you already run rather than a fifth one of our own; and a warm secondary in another network that agents fail over to on their own when the primary becomes unreachable -- the agent carries an ordered list of servers rather than a single address. Promotion is explicit and fenced, so a broken link cannot leave two servers both accepting check-ins. Enterprise.
