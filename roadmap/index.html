Roadmap

SysManage ships in four editions -- Community Edition, Professional, Enterprise, and Enterprise SaaS -- built from one codebase and one agent. Below is a snapshot of what's available today, what shipped recently, and what we're building next. Target releases aren't promises: priorities move with what operators actually need.

Available today

A summary of each edition. The editions page has the full table, with the release that shipped each capability, and the supported platforms page says what each one does on each operating system.

🏠

Community Edition

Free and open source under the AGPLv3, self-hosted, with no limit on hosts. One agent for Linux, Windows, macOS, FreeBSD, OpenBSD and NetBSD; hardware, software and certificate inventory; endpoint facts in osquery's table schema, natively on OpenBSD and NetBSD where osquery does not exist; package installs, updates and OS upgrades; maintenance windows, blackouts and emergency overrides; hardware health, clock measurement with one-click resynchronization, and asset tags bound to the machine; scripts; users and groups; configuration on one host with Ansible or PowerShell DSC; firewall and antivirus status; role-based access control, multi-factor sign-in and the audit log; the REST API; running against a high-availability PostgreSQL cluster; an interface in 14 languages; and host backups with restate, in preview.

📊

Professional

Everything in Community, plus health analysis with score history, CVE vulnerability scanning, vendor advisory management (Ubuntu security notices and OpenBSD errata today), OS end-of-life tracking with release upgrades, CIS and DISA STIG compliance checks on Linux, alerting to email, webhook, Slack and Teams, PDF and HTML reports, a tamper-evident audit trail with export and SIEM forwarding, secrets management with OpenBAO, query packs, and encrypted, signed backups with retention policies, in preview.

🏢

Enterprise

Everything in Professional, plus single sign-on (LDAP and Active Directory, OIDC, SAML, SCIM), FIPS mode, fleet firewall policy, antivirus deployment and malware detection, the advisor with a threat model and security posture, built-in host metric graphs, discovery of unmanaged devices, OpenTelemetry, Grafana and Graylog integration, fleet jobs and rolling deployments, a script library with scheduling and approvals, Puppet, Salt and Chef profiles with drift detection, fleet time-server policy, virtual machine lifecycle, provisioning on libvirt, Proxmox and bare metal over PXE, repository mirroring, content views with lifecycle promotion, a Snap Store proxy, OCI image content and image-mode hosts, air-gapped deployment, and multi-site federation.

🌏

Enterprise SaaS

Everything in Enterprise, plus multi-tenancy: each tenant in its own database, customer-owned SSO, and per-tenant edition assignment. Run it yourself, or have us host it on request. Measured on one 12-thread machine across 20 tenants: a server-restart storm of 10,000 simulated agents drained completely with no host marked down, and 20,000 agents also drained completely, with 2 hosts marked down. See performance and scale.

Recently shipped

These used to sit on this page as plans. They are in the current release.

Fleet backup & recovery

In preview since v3.12. Every host backed up with restate to its own repository on one storage host, which locks each finished backup so even root on the host cannot change or delete it, seals it with a ZFS or btrfs snapshot, prunes and checks. Files come back into a staging directory after a preview. One target, per-host schedules, Back up now and file restore are in Community; Professional adds policies by tag, longer retention schedules, encryption with keys held in OpenBAO, signed snapshots, alerts and package-level restore.

Provisioning & discovery

Bare-metal PXE provisioning, per-machine OS assignment, hardware discovery, and provisioning onto external hypervisors, on remote libvirt and Proxmox. Enterprise. Compute providers for EC2, Azure, GCE and VMware vSphere are not built yet; they are planned.

Configuration management at fleet scale

Desired-state configuration across Ansible, PowerShell DSC, Puppet, Salt and Chef, with scheduled enforcement per host, tag or site, baseline capture, drift detection and one-click remediate-to-baseline. Inventories built from your hosts, tags and sites, job templates that run one profile across many machines in bounded waves with a per-host result, and remediation playbooks that repair a single divergence rather than re-applying a whole baseline. Configuration on one host with Ansible or PowerShell DSC is Community; the fleet-scale work is Enterprise.

Proactive operations & advisor

The advisor: risk-scored recommendations across your collected facts, CVEs, compliance results and configuration state, with curated rule packs and proposed fixes, and a guided threat-model wizard that turns your answers into a prioritized posture punch list with audited waivers. Built-in host metric graphs: CPU, memory, swap, load and disk history for every host, charted per host and across the fleet, and exposed on the Prometheus endpoint for Grafana. Malware detection: each host scans itself with its own ClamAV and a YARA rule feed the server keeps current, fleet scans run as jobs a bounded number of hosts at a time, and quarantine moves files rather than deleting them. All Enterprise.

Unmanaged asset visibility

Network discovery: agents already sit inside each segment, so they report the neighbors they hear -- ARP and neighbor listening, mDNS and SSDP, with active sweeps opt-in, on-link only, rate-limited and audited -- and anything already covered by a managed host is filtered out. The result is a review page, not an onboarding pipeline: SysManage detects unenrolled machines but does not force-enroll them, because that would need credentials on the target and reintroduce the inbound access the architecture deliberately avoids. Devices you would never manage -- a printer, a switch, a virtual router address -- can be marked as known, with a reason and an owner recorded. On Windows the agent reads the ARP cache only. Enterprise.

On the roadmap

What is planned, in order, with the release each part is aimed at. The next stretch closes the gap with established fleet-management tools while keeping our footing as the management-and-remediation plane rather than another agent to babysit. Target releases are plans, not promises: priorities move with what operators need.

Fleet backup at scale -- v3.13

Per-site storage through federation, restore readiness, bare-metal rebuild and clones, fleet-wide restore jobs, four-eyes approval, legal hold, restore drills, and off-site, immutable and air-gap copies at Enterprise; backup multi-tenancy at Enterprise SaaS.

Automatic update application -- v3.14

Policies that apply updates on a schedule, with reboot handling, per-host opt-outs, holds and pinned packages respected (Community); runs kept inside maintenance windows, with separate waiting periods for regular and critical-CVE patches (Professional); rollout one fleet at a time with health gates (Enterprise).

Mobile devices & MDM

v4.0 and v4.1, then v6.0 and v6.1. Phones and tablets as a first-class endpoint class rather than an afterthought: inventory and OS / patch-level visibility for iOS, iPadOS and Android, and ingestion from the UEM you already run -- Microsoft Intune, Jamf Pro, Workspace ONE, Kandji; a companion self-report app for the BYOD devices no UEM covers; and later native MDM authority over the Apple MDM protocol and the Android Management API, with zero-touch enrollment. Native MDM needs internet access and cannot be air-gapped.

Proven at 50,000 agents

v5.0. Scale hardening has shipped: 10,000 simulated agents measured on one tenant and across 20 tenants, and 20,000 across 20 tenants. Next comes the 50,000-agent proof across many tenants and sites on dedicated server hardware, with the measured results folded into the scaling guide's sizing advice. Applies to every edition.

Broader hardware support

v5.1. The agent on the enterprise iron and emerging silicon beyond x86-64 and arm64 -- IBM Power (ppc64le), IBM Z (s390x) and RISC-V (riscv64), including the big-endian correctness work that s390x demands. The agent is open source, so this lands in Community Edition.

Security tooling coexistence

v5.2. Meeting you where you are rather than replacing what you already run: orchestrating Velociraptor for incident response and threat hunting, and ingesting Wazuh alerts into the same alerting, reporting and audit surfaces as everything else. Enterprise.

High availability & disaster recovery

v6.2. Survive losing a server, and survive losing a site. Several SysManage servers running active behind a load balancer, with the scheduled work leader-elected so it still runs exactly once; integration with the PostgreSQL failover managers you already run rather than one of our own; and a warm secondary in another network that agents fail over to on their own when the primary becomes unreachable. Promotion is explicit and fenced, so a broken link cannot leave two servers both accepting check-ins. Enterprise.

Browser remote terminal

v6.3. An interactive shell on any managed host, straight from the web UI -- tunneled through the agent's existing connection, so it needs no inbound port, no running SSH server and no keys, and never changes the host's security posture to make it work. Every session is audited. The terminal itself is Community Edition; session recording and playback arrive at Professional, and second-person approval before a session opens at Enterprise.

Targeting by site and network segment

v6.4. Choose where fleet work runs the way large estates are laid out: by site in a multi-site deployment, and by network segment -- named sets of address ranges -- within a site or a single-site install, with per-site and per-segment limits on how many hosts work at once. Enterprise.

Dashboard insight cards -- v6.5

A home screen that answers "what needs me today?" across everything SysManage already measures: cards for approvals, check-ins, certificates, disk, firewall, vulnerabilities, advisories, end of life, compliance, alerts, malware, drift, fleet jobs, unmanaged devices, sites and air-gap freshness, across Community, Professional and Enterprise.
