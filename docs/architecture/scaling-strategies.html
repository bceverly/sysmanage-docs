Scaling

How SysManage grows with the fleet.

A SysManage server scales by running more worker processes on its machine. Each worker serves its agents from one event loop; the workers share one PostgreSQL database and coordinate through it, so no cache or message broker is needed between them.

With multi-tenancy, each tenant has its own database, which can be placed on another PostgreSQL server to take its connections and load off the main one.

How many agents one server carries, how to size its CPU, memory and database connections, and what to expect after a restart were measured, not estimated. They are in the Scaling Guide.
