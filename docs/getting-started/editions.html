Editions and Availability

One server, one agent and one user interface in every edition. A license adds capabilities to the same installation; nothing is reinstalled when you move from one edition to the next. This page lists every capability, the edition that includes it, and whether it is available today, in preview, or planned.

The four editions

  • Community -- free and open source (AGPLv3), with no limit on the number of hosts. Inventory, updates, OS upgrades, maintenance windows, scripts, users and groups, role-based access control, multi-factor sign-in, the audit log, the API and host backups.
  • Professional -- everything in Community, plus vulnerability scanning, CIS and DISA STIG checks, vendor advisories, OS lifecycle, alerting, reports, secrets management, health analysis, and encrypted, signed backups.
  • Enterprise -- everything in Professional, plus fleet jobs and automation, configuration management with drift detection, firewall and antivirus orchestration, malware detection, virtualization and provisioning, repository mirroring, air-gapped deployment, multi-site federation and single sign-on.
  • Enterprise SaaS -- everything in Enterprise, plus multi-tenancy: many isolated fleets on one installation, each tenant in its own database. You can run it yourself, or we host it for you on request.

How to read availability

  • Since 3.9 -- available today; the number is the release that first shipped it.
  • Preview -- in the current release and usable, while its final production proof is still being completed. Expect details to change.
  • Planned -- on the roadmap, with the phase and the release it is aimed at. Not available yet.

An edition says what a capability costs, not where it runs. Many capabilities work differently on different operating systems -- see Supported Platforms for what each one does on Linux, Windows, macOS, FreeBSD, OpenBSD and NetBSD.

If a license lapses

Your own data stays yours. Restoring backups -- encrypted ones included -- and exporting your backup keys keep working without a license. What stops is new paid capability, such as creating new keys, scheduled verification or tag-based backup policies.
