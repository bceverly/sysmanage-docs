Supported Platforms

Supporting an operating system is not the same as every capability working identically on it. This page says both: where the server and the agent install, and what each capability does on each operating system -- including where it does less.

What each capability does on each operating system

Yes means the capability works fully on that operating system. Partial means it works with the limits given in the numbered note. No means it is not available there. Capabilities that run on the server, such as reports or alerting, work the same for every host and are not listed. For which edition includes each capability, see Editions and Availability.
