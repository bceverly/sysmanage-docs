Air-gap is a first-class deployment mode, not a workaround

Some vendors bolt on an "offline mode" that quietly degrades. SysManage treats the disconnected appliance as one of its core shapes, with a clear, auditable set of invariants: a single tenant, a single database, local secret storage, and no outbound calls of any kind.

🔌

Zero phone-home

No license check-ins, no telemetry, no update pings. The appliance operates indefinitely with no route off the network.

🗄️

Local secret storage

Secrets are sealed by a local vault on the appliance itself — no external key-management service, no cloud dependency.

💿

Content on physical media

Packages, patches, container images, and vulnerability data are collected outside, exported to an ISO, and carried across the gap — then served locally.

🧩

Single-tenant appliance

A deliberately simple, self-contained topology: one tenant, one database, one vault. Fewer moving parts is a security property, not a limitation.

Content lifecycle across the gap

SysManage mirrors the repositories, container images, and advisories you approve on a connected staging host, snapshots them into an immutable content view, and materializes that view onto an ISO. Carry it in, import it, and every managed host inside the enclave patches from a local, versioned, digest-verified source.

  • Curated, versioned content views — promote the exact bytes you tested
  • Digest-pinned packages and images for tamper-evident delivery
  • Offline vulnerability and advisory data, refreshed on your schedule

Local repositories, every platform

Inside the enclave, SysManage serves as the local source of truth for Windows, Linux, macOS, and the BSDs alike. The same air-gap pipeline that feeds your Debian and RHEL hosts also feeds FreeBSD, OpenBSD, and NetBSD — platforms that dominate defense, networking, and critical infrastructure and that other tools leave stranded offline.

  • One offline pipeline for all six operating systems
  • First-class BSD support where it matters most
  • Full inventory, patching, compliance, and vulnerability management — disconnected
